# Reading the Trees - Zine Anthology

A hyperlocal zine anthology celebrating trees through art, stories, and field guides from around the world.

## About

This project showcases 80 community-made zines about trees, each telling a unique story about place, nature, and connection.

## Features

- Interactive grid gallery of all 80 zines
- Click to view detailed information
- Optimized WebP images for fast loading
- Responsive design
- Clean, minimal aesthetic matching Hyperlocal brand
